# Каталог локальных skills

Сторонние skills намеренно не включены.

Перед добавлением любого skill:

1. Прочитайте `docs/SKILLS_SECURITY.md`.
2. Проверьте источник, лицензию и дату обновления.
3. Просмотрите `SKILL.md`, `scripts/` и другие исполняемые файлы.
4. Определите необходимые разрешения и сетевой доступ.
5. Проведите первый запуск в тестовом репозитории или контейнере.
6. Не добавляйте несколько skills, выполняющих одну и ту же задачу.

Помните: skill может содержать исполняемый код, а не только текстовые инструкции.
