# План: COMP-001 — Переиспользуемый компонент сайдбара

## Контекст

Проект Reputa (React 18 + Vite + plain CSS + react-router-dom v6 + i18next). Все маршруты `/user/*` и `/employee/*` сейчас рендерят bare `PlaceholderPage`. Нет ни сайдбара, ни layout-обёрток, ни auth-контекста на фронтенде, ни библиотеки иконок. Иконки lucide-react указаны в задании как обязательные — установка требуется.

## Изменения

### 1. Установить lucide-react

**Файл:** `frontend/package.json`

Добавить `"lucide-react": "^0.468.0"` в `dependencies`, затем `npm install`.

### 2. Добавить i18n-ключи для пунктов сайдбара

**Файл:** `frontend/src/locales/ru.json`

Добавить новый неймспейс `sidebar`:

```json
"sidebar": {

  "actualApplications": "Актуальные заявки",
  "allApplications": "Все заявки"

```

### 3. Создать AuthContext (определяет роль пользователя)

**Файл:** `frontend/src/contexts/AuthContext.jsx`

Поскольку auth на бэкенде не реализован (задачи AUTH-001..007 в статусе pending), создаём минимальный контекст, который определяет роль из URL-пути (`/user/*` → `"user"`, `/employee/*` → `"employee"`). Это forward-compatible: когда появится JWT-auth, провайдер будет обновлён для чтения роли из токена/API, а компонент Sidebar не потребует изменений.

```jsx
// AuthContext — роль определяется из текущего URL-пути
// Когда auth будет реализован — заменить на чтение роли из JWT
```

Экспорт: `AuthProvider`, `useAuth` (возвращает `{ role }`).

### 4. Создать компонент Sidebar

**Файл:** `frontend/src/components/Sidebar.jsx`

Логика:
- `useState` для `collapsed` (boolean, по умолчанию `false`)
- `useState` для `width` (number в px, по умолчанию `240`)
- Вызывает `useAuth()` для получения `role`
- На основании `role` формирует массив пунктов меню (иконка + текст + путь)
- Использует `useLocation()` из react-router для определения активного пункта
- Тексты — через `useTranslation()` с ключами `sidebar.*`
- Иконки — из `lucide-react`:
  - user: Settings → `Settings`, Мои заявки → `FileText`, Создать заявку → `Pencil`
  - employee: Settings → `Settings`, Актуальные заявки → `Clock`, Все заявки → `LayoutList`

Функционал resize:
- Невидимая зона захвата (`sidebar__handle`) ~8px на правом крае сайдбара, `cursor: col-resize`, без визуального стиля
- `border-right: 1px solid var(--border)` на самом `<aside>` служит визуальной «ручкой» для пользователя
- `onMouseDown` на зоне запускает drag: слушаем `mousemove`/`mouseup` на `document`
- При drag вычисляем новую ширину, ограничиваем `min` (60px — ширина только иконок) и `max` (30vw)
- При `mouseup` снимаем слушатели

Функция collapse:
- Кнопка-переключатель (иконка `ChevronLeft` / `ChevronRight`) в верхней части сайдбара
- При `collapsed=true`: ширина принудительно 60px, текст скрыт (`overflow: hidden`), логотип показывает только иконку/букву, tooltip на hover пунктов с названием
- При `collapsed=false`: показывается иконка + текст, ширина из `width` (но не менее 160px и не более 30vw)

Структура JSX:
```
<aside className={sidebar} data-collapsed={collapsed} style={{ width }}>
  <div className="sidebar__header">
    <button className="sidebar__toggle" onClick={toggle}>
      <ChevronLeft /> или <ChevronRight />
    </button>
  </div>
  <nav className="sidebar__menu">
    {items.map(item => (
      <NavLink to={item.path} className="sidebar__item" title={item.label}>
        <item.icon size={20} />
        <span className="sidebar__label">{item.label}</span>
      </NavLink>
    ))}
  </nav>
  <div className="sidebar__footer">
    <hr className="sidebar__divider" />
    <span className="sidebar__logo">Reputa</span>
  </div>
  <div className="sidebar__handle" onMouseDown={onResizeStart} />
</aside>
```

Активный пункт: класс `sidebar__item--active` — подсветка `color: var(--accent)` + фон `var(--accent-bg)`.

### 5. Создать CSS для Sidebar

**Файл:** `frontend/src/components/Sidebar.css`

Стили:
- Ширина задаётся через `style` проп, CSS-переменная `--sidebar-w`
- Высота `100vh`, `border-right: 1px solid var(--border)`, `position: relative`
- `transition: width 0.2s ease` для плавного collapse/expand
- Flexbox column, `justify-content: space-between`
- `min-width: 60px` (только иконки), `max-width: 30vw`
- Пункты: `padding`, `gap: 10px` для иконки и текста, `text-decoration: none`, `color: var(--text-muted)`
- `white-space: nowrap` на `.sidebar__label`
- `[data-collapsed] .sidebar__label` — `display: none`
- `[data-collapsed] .sidebar__logo` — показать только иконку/первую букву
- Активный пункт: `color: var(--accent)`, `background: var(--accent-bg)`, `border-radius`
- Hover: `background: var(--accent-bg)`
- Логотип: шрифт RockStar, акцентный цвет
- Кнопка toggle: в углу, полупрозрачная, `hover` — видимая
- Handle: невидимая зона захвата `position: absolute`, `right: 0`, `top: 0`, `height: 100%`, `width: 8px`, `cursor: col-resize`, без фона/цвета — за схватку служит `border-right: 1px solid var(--border)`
- `[data-collapsed] .sidebar__handle` — скрыта (нельзя drag из collapsed состояния)

### 6. Создать компонент Layout

**Файл:** `frontend/src/components/Layout.jsx`

Обёртка для авторизованных страниц:
```jsx
<div className="layout">
  <Sidebar />
  <main className="layout__content">
    <Outlet />
  </main>
</div>
```

Стили (`Layout.css`):
- `display: flex`, `min-height: 100vh`
- `.layout__content` — `flex: 1`, `min-width: 0` (чтобы контент не распирал flex)
- Контент адаптируется к ширине сайдбара автоматически (flex)

### 7. Обновить маршруты в App.jsx

**Файл:** `frontend/src/App.jsx`

Вложить все `/user/*` и `/employee/*` маршруты под единую Layout-обёртку с `AuthProvider`:
