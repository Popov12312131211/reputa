# STMT-001 — Парсинг банковской выписки

## Дата
2026-09-05

## Статус
Выполнена.

## Что сделано
- Реализован модуль `backend/app/scoring/stmt_parser.py`:
  - `parse_statement(content, filename)` — основной вход: читает PDF (pdfplumber),
    распознаёт банк и разбирает в `ParsedBankStatement`.
  - `detect_bank` — распознавание банка по реквизитам шапки/подвала. Порядок
    маркеров продуман: в выписках реальных банков в описаниях операций
    встречаются названия чужих банков («перевод из ПАО Сбербанк» в Альфа-Банке,
    «Альфа-Банк» в выписке СберБанка), поэтому первыми проверяются уточнённые
    реквизиты («ООО «ОЗОН БАНК»», «АО «АЛЬФА-БАНК»», «СБЕРБАНК ОНЛАЙН»).
  - Парсеры Альфа-Банка, СберБанка и Озон Банка: остатки, период, номер счёта,
    поступления (income), расходы (expenses), расходы по категориям.
  - `_categorize`: сначала MCC-коды (5411/5811-5814/5912/4111-4131/4816/7277),
    затем ключевые слова по приоритету; поступления всегда категоризуются как
    «поступления».
  - Исключения `StatementParseError` / `UnsupportedStatementError`.
- Схемы: `backend/app/schemas/statement.py` — `StatementTransaction`,
  `ParsedBankStatement`.
- Константы: `backend/app/core/constants.py` — банки, категории,
  `MSG_STATEMENT_UNPARSABLE`.
- Подключено в `POST /applications` (`backend/app/routers/applications.py`):
  после проверки размера файл парсится; при `StatementParseError` → 422 с
  `MSG_STATEMENT_UNPARSABLE`. Файл не сохраняется.
- Фикстуры: `backend/tests/fixtures/{alfa,sber,ozon}.pdf` (копии из
  `backend/vipiski/`, которое в git не трекается).
- Тесты: `backend/tests/test_statement_parser.py` (даты/остатки/итоги сверены с
  шапками выписок, категории, негативные кейсы); в `tests/test_applications.py`
  фейковый PDF заменён на фикстуру и добавлен кейс нечитаемой выписки → 422.

## Замечания по форматам
- Сбер: списание в колонке суммы печатается без знака, пополнение — со знаком
  «+»; знак восстановлен в `_parse_sber`.
- Сбер: категория операции — «ленивый» захват (`.+?`), иначе остаток съедает
  конец строки.
- Озон: суммы вида `- 1 000.00 ₽` — `_parse_amount` отбрасывает валютный суффикс.
- Альфа: HOLD-операции (unconfirmed) включены в расходы и учитываются в итогах.
