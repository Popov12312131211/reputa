# UI-001 — Ресстилизация лендинга под общий дизайн-язык проекта

## Статус
Выполнено.

## Что сделано
Приведён визуальный стиль лендинга (`Landing.css`) в соответствие с общим дизайн-языком проекта. Структура блоков (хиро-секция, сравнение «как сейчас»/«с сервисом», футер) не менялась — только визуальный стиль элементов.

Основные изменения:
- Рамки секций (шапка, `hero__left`/`hero__right`, `info`, `footer`) и кнопки хиро переведены с тёмного `--text-muted` (#6E7168) на светлый токен `--border` (#E6E3D9), который используется для рамок карточек на всех остальных страницах (Login, Registration, UserMy, UserSettings и т.д.).
- Кнопка «Попробовать» в хиро переведена со стиля «контурная кнопка с тёмной рамкой» на акцентную залитую кнопку проекта (фон `--accent`, белый текст, hover → `--accent-hover`) — как submit-кнопки форм в остальном приложении.
- Заголовки (`hero__title`, `info__lead`, `col__title`) переведены с Inter на фирменный шрифт `RockStar` с `font-weight: 400` — как заголовки страниц на остальных экранах (`--page__title` в UserMy/UserSettings/UserNew).

## Затронутые файлы
- `frontend/src/components/Landing.css` (только стили; структура JSX и i18n-ключи не менялись)

## Типографика и отступы (доп. правки)
- Заголовки секций сравнения (`.info__lead`, `.col__title`) уменьшены вдвое (clamp 1–2rem, Inter weight 200) — больше не догоняют основной хиро-заголовок, колонка «С нашим сервисом» помещается по ширине.
- Значения в парах «подпись/значение» (`.block__value`) уменьшены с 1–2rem до 0.875–1.5rem; подписи (`.block__label`) не менялись.
- Акцентный шрифт RockStar оставлен только для текста «Reputa» в логотипе (шапка/футер); все заголовки (`hero__title`, `info__lead`, `col__title`) и body переведены на Inter.
- Увеличены отступы: вертикальный зазор между секциями (`.page` → `gap` 2–4rem), внутренний padding `.info` (2–4rem), зазор между колонками (2.5–5rem) и между парами внутри колонки (1.5–3rem).
- Добавлен медиа-запрос `≤1100px`: длинные `nowrap`-подписи переносятся, чтобы ни один текст не вылезал за правый край на средних экранах.

## Auto-hide хедер на Hero (доп. правки)
- Хедер в верхней части страницы (Hero, `scrollY === 0`) по умолчанию скрыт: `transform: translateY(-100%)` + `opacity: 0`.
- Добавлена триггерная зона наведения `.landing-trigger` (fixed, высота 40px) в самом верху экрана: по hover показывает/скрывает хедер плавно (`transition` по `transform`/`opacity`, 0.25s).
- При прокрутке вниз (ниже Hero) хедер прилипает (fixed) и остаётся видимым без наведения; при возврате наверх снова активируется скрытие по наведению.
- Логика: `Landing.jsx` — состояния `atTop` (по `window.scrollY`) и `peekVisible` (по `mouseenter`/`mouseleave` на триггере и хедере); хедер получает класс `header--hidden` только когда вверху и нет наведения.
- При скрытом хедере `pointer-events: none`, чтобы он не перехватывал клики; триггер-зона сама по себе без интерактивных элементов.

## Проверка
- `npm run build` — сборка прошла успешно.
- Headless-рендер (1920px): горизонтального переполнения страницы нет (scrollWidth == clientWidth), `.info` не обрезается, контент `.col--with` не выходит за границы контейнера.
- Computed style: логотип — RockStar; хиро-заголовок, `info__lead`, `col__title` — Inter.
- Поведение хедера (headless, прокрутка + мышь): вверху скрыт → по hover триггерной зоны появляется → при уходе скрывается → при прокрутке вниз прилипает и остаётся → при возврате наверх снова скрыт. Все состояния подтверждены через `opacity`/`transform`/класс.
