# APP-004 — Список заявок пользователя (frontend `/user/my`)

## Статус
Выполнено (вёрстка + логика фильтра; данные — заглушка, т.к. бэкенд-эндпоинт ещё не реализован).

## Что сделано
- Создан `frontend/src/components/UserMy.jsx` + `UserMy.css`.
- Заголовок «Мои заявки» сверху (`userMy.title`).
- Карточка-таблица с колонками: ID, Статус, Сумма, Рейтинг.
- Иконка фильтра справа от заголовка «Статус» — открывает выпадающее меню: Все / В обработке / Одобрено / Отклонено.
- ID — сокращённая форма с многоточием («123DE...») — мок уже приходит в сокращённом виде.
- Статус — иконка в кружке по группе: часы (в обработке), галочка (одобрено), крестик (отклонено).
- Сумма — с ₽, форматирование ru-RU.
- Рейтинг — 0–100; при отсутствии (заявка в обработке) — «—».
- Строки НЕ кликабельны (переход на детальную карточку — APP-005, будущая задача).
- Пустое состояние «Заявок пока нет» + ссылка на `/user/new` вместо пустых строк таблицы.
- Стили переиспользуют палитру проекта (те же CSS-переменные, радиус 24px, поля/кнопки в стиле UserNew).
