# EMP-002 — Настройка порогов автоматизации (backend + frontend)

## Дата
2026-09-05

## Статус
Реализована.

## Что сделано
- Backend:
  - `app/routers/employee.py` (новый) — роутер `/employee`:
    - `GET /employee/settings` — чтение порогов (переиспользует `get_threshold_settings` из APP-003).
    - `PUT /employee/settings` — обновление порогов в `threshold_settings`.
  - `app/schemas/threshold.py` (новый) — `ThresholdSettingsUpdate` с валидацией: пороги в диапазоне 0–100 (SCORE_MIN/SCORE_MAX) и инвариант `auto_reject < auto_approve` (иначе авто-одобрение недостижимо в `decide_auto_status`, см. APP-003). `ThresholdSettingsResponse` для GET.
  - `app/core/constants.py` — сообщения валидации `MSG_THRESHOLD_OUT_OF_RANGE`, `MSG_THRESHOLD_REJECT_BELOW_APPROVE`.
  - `app/main.py` — подключён роутер employee_router.
- Frontend:
  - `components/EmployeeSettings.jsx` + `.css` (новые) — страница `/employee/settings` с блоком "Автоматизация": два числовых поля порогов, клиентская валидация (0–100 и reject < approve), сохранение через `PUT /api/employee/settings`.
  - `src/api.js` — добавлен helper `putJSON` (по образцу `postJSON`).
  - `src/constants/threshold.js` (новый) — диапазон 0–100.
  - `src/App.jsx` — маршрут `/employee/settings` подключён к странице.
  - `src/locales/ru.json` — ключи `employeeSettings.*` (все строки через i18n).
