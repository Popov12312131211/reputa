## Что сделано
- Эндпоинт `POST /applications` (multipart/form-data) в `app/routers/applications.py`: принимает `amount`, `purpose`, `telegram`, `telegram_channel` и файл выписки `statement`; создаёт `Application` со статусом `in_queue` и `score=None`; привязка к пользователю через JWT из httpOnly cookie.
- Схемы в `app/schemas/application.py`: `ApplicationCreate` (валидация по образцу `schemas/auth.py`: сумма > 0, strip + непустые поля, префикс `@`, лимиты длины) и `ApplicationResponse` (`from_attributes`). Хелпер `_strip_required` переиспользован из `schemas/auth.py`.
- `app/services/security.py` (новый): `create_access_token` / `decode_access_token` (PyJWT, HS256, TTL и алгоритм из настроек `JWT_SECRET`/`JWT_EXPIRE_MINUTES`/`JWT_ALGORITHM`). Выдача токена — на AUTH-002.
- `app/api/deps.py` (новый): зависимость `get_current_user` — читает JWT из cookie `access_token`, при отсутствии/невалидности/неизвестном пользователе → 401. Переиспользуется AUTH-007.
- `app/core/constants.py`: `AMOUNT_MIN_VALUE`, `STATEMENT_MAX_SIZE_BYTES`, `JWT_COOKIE_NAME`, `MSG_AUTH_REQUIRED`, `MSG_STATEMENT_TOO_LARGE`.
- `requirements.txt`: добавлены `PyJWT==2.10.1`, `python-multipart==0.0.20` (нужен для Form/File).
- `app/main.py`: роутер подключён.
