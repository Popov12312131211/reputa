# Доделывание INFRA-003 — применение миграции к реальной БД

## Дата
2026-09-04

## Что сделано
- Развёрнут локальный Postgres 16 через `docker compose up -d` (новый `docker-compose.yml` на уровне проекта, том `reputa_pgdata`).
- Создан `backend/.env` с `DATABASE_URL` (postgres@localhost:5432/reputa) и `JWT_SECRET`.
- Исправлена типизация модели `User` в `backend/app/models/user.py`: `birth_date` → `Mapped[date]`, `created_at`/`updated_at` → `Mapped[datetime]`; длина роли вынесена в константу `ROLE_MAX_LENGTH` (вместо магического `20`).
- Применена миграция к реальной БД: `alembic upgrade head` — создана таблица `users`, `alembic_version` = 0001.
- Проверен `GET /health` — теперь возвращает `{"status":"ok","database":"connected"}` (раньше было `disconnected` из-за отсутствия Postgres).
