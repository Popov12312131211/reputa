# Выполнение APP-009 — автоматический запуск скоринга при создании заявки

## Статус
Выполнено.

## Что сделано
- При создании заявки `stmt_parser` разбирает выписку, а `stmt_scoring.score_statement` рассчитывает итоговый результат.
- Итоговый балл записывается в `Application.score`, детали — в `ScoreResult`.
- После расчёта вызывается `apply_auto_decision` из APP-003/APP-008.
- Заявка, результат скоринга и автообработка сохраняются одним `db.commit()`; исходный файл не сохраняется.
- При исключении скоринга транзакция откатывается, а endpoint возвращает контролируемую ошибку.
- Тест создания заявки проверяет независимый ожидаемый результат для фиксированной Sber-файловой фикстуры.

## Затронутые файлы
- `backend/app/routers/applications.py`
- `backend/app/services/auto_processing.py`
- `backend/tests/test_applications.py`
