## Что сделано (этап 2 — валидация суммы, поле пароля, ротация плейсхолдера)
- Создан `frontend/src/constants/application.js` с `AMOUNT = { MIN: 1000, MAX: 10000000 }` (RULES: константы не в бизнес-логике).
- Валидация суммы по `AMOUNT.MIN/MAX` (атрибуты `min`/`max` на инпуте тоже). Сообщение об ошибке — `userNew.amountHint`, «Укажите сумму больше нуля».
- Поле «Пароль» рядом с «Запросить» в `.usernew-actions` (flex-ряд): верификация личности, валидация только «не пустое» (корректность — на бэкенде при APP-002), глазик show/hide — копия паттерна `/login` и `/registration`, aria-ключи через i18n. Без пароля кнопка disabled.
- Ротация плейсхолдера «Причины»: 7 готовых коротких плейсхолдеров (`reasonPlaceholder1..7`), случайный выбор индекса в `useState`-инициализаторе — только при монтировании, не при ре-рендерах.
- Вёрстка и валидация телеграм-канала не тронуты; пароль/кнопка в одном ряду.
